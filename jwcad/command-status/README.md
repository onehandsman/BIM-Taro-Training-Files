# Jw_cad 10.01.8 操作確認コマンド一覧

「BIM太郎」のJw_cad入門動画を制作する際に、Windows版 Jw_cad 10.01.8で実機確認した範囲を公開しています。

この表の「一部確認」は、そのコマンドの全設定・全分岐を習得した意味ではありません。初心者向け動画で使った基本経路を確認した、という意味です。Jw_cadの版や設定により、画面配置・表示・挙動が異なる場合があります。

## 状態の見方

| 表示 | 意味 |
|---|---|
| 基本経路を確認 | 動画で扱う基本的な操作を実機で確認 |
| 一部の方式を確認 | コマンド内の一部設定・一部経路を実機で確認 |
| 保留 | 追加の実機検証が必要 |

## マウス操作の保留事項

通常の左クリック・右クリックは、上表に記載した基本経路で確認しています。

一方、Jw_cad固有の**左右ボタン同時操作を使う画面移動・拡大などのジェスチャー**は、操作環境からの完全再現を追加検証する必要があるため保留です。代替として、キーボードの `PageUp`、`PageDown`、`Home` を使う表示操作は確認しています。

範囲選択についても、呼び出し元コマンドにより確定ボタンの表示が変わります。単独の［編集→範囲選択］と、［図形移動］などの内部で使う範囲選択を同一操作として扱わないよう、追加検証の対象にしています。
